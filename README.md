# 🌦️👕 Weather Wardrobe — умный подбор одежды по погоде

Веб-приложение, которое по погоде в любом городе мира подсказывает, что надеть. Рекомендации строит модель машинного обучения, а погодные данные берутся из OpenWeatherMap.

> Проект выполнен для конференции «Инженеры будущего» в детском технопарке «Альтаир» РТУ МИРЭА.

> Научные руководители: Р. И. Черкасов, М. В. Карева.

## 💡 Зачем это нужно

Неправильно подобранная одежда — это простуды, обморожения, солнечные удары и ожоги. Мороз с солнцем обманчив, жара у моря коварна, а приезжим сложно понять, как одеваться в незнакомом климате. Программа учитывает температуру, ветер, влажность, осадки, время суток и сезон и даёт понятный совет.

## ✨ Возможности

- Рекомендации по одежде для любого города из базы OpenWeatherMap
- Учёт 18 признаков: температура и «ощущается как», влажность, ветер, давление, видимость, осадки, час дня, месяц, сезон
- 8 категорий одежды: от `ЗИМНИЙ_ПОЛНЫЙ` до `ЖАРКИЙ_МИНИМАЛЬНЫЙ`, а также дождевой, ветровой и влажный режимы
- Определение дня и ночи в выбранном городе (по времени восхода и заката)
- Лайк/дизлайк рекомендаций: оценки сохраняются и используются для дообучения модели
- Переобучение модели на новых данных прямо из приложения
- Интерфейс с карточками и эмодзи

## 🏗️ Как это устроено

Трёхзвенная архитектура «клиент — сервер — ML-модель»:

| Уровень | Технологии | Что делает |
| --- | --- | --- |
| Клиент | HTML, CSS, JavaScript | Ввод города, показ карточек с рекомендациями |
| Сервер | Python, Flask | Запросы к погодному API, обработка данных, маршруты |
| ML | scikit-learn (`GradientBoostingClassifier`) | Предсказывает категорию одежды по погодным признакам |

Поток данных:

```
Пользователь → город → Flask → OpenWeatherMap → 18 признаков → ML-модель → JSON → браузер
```

Модель обучается на синтетическом датасете (10 000+ примеров с реалистичными диапазонами погоды: от −35 °C до +45 °C). Точность на тестовых данных — более 85 %.

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git
   cd НАЗВАНИЕ_РЕПОЗИТОРИЯ
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Получите бесплатный API-ключ на [openweathermap.org](https://openweathermap.org/api) и создайте файл `.env` в корне проекта:
   ```
   OPENWEATHER_API_KEY=ваш_ключ
   ```
4. Запустите приложение:
   ```bash
   python app.py
   ```
5. Откройте в браузере: http://localhost:5000

> ⚠️ Файл `.env` с ключом нельзя выкладывать на GitHub. Добавьте его в `.gitignore`.

## 🔌 API приложения

| Маршрут | Метод | Описание |
| --- | --- | --- |
| `/` | GET | Главная страница |
| `/weather?city=Москва` | GET | Погода и рекомендации по одежде |
| `/save_preference` | POST | Сохранить лайк/дизлайк |
| `/ml_info` | GET | Статистика модели: точность, число записей, статус |
| `/retrain_model` | POST | Переобучить модель |
| `/cities` | GET | Список популярных городов |

## ⚠️ Ограничения

- Модель обучена на синтетических данных, а не на реальных предпочтениях людей
- Личные особенности пользователя (например, как быстро он мёрзнет) пока не учитываются
- Ограниченный набор категорий не охватывает модные и стилевые предпочтения
- Прогноз погоды (`FORECAST_URL`) подключён в коде, но пока не используется на сайте
